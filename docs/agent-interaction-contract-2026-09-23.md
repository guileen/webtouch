# WebTouch Agent 互动入口契约（首版）

> 状态：`DRAFT · DOGFOOD_PASS`（2026-09-23 14:48）。Agent 入口采用现有 Local Skill + CLI。
> 真实浏览器闭环五步已走通（见 [`evidence/pilots/dogfood-live-2026-09-23.md`](evidence/pilots/dogfood-live-2026-09-23.md)）；
> 语义抽取层的假阴性/假阳性缺陷已定位待修；在线 VLM learned 接线仍未启用。

## 产品目标

让 Codex 等 Agent 能把真实网页作为工作环境：Agent 理解用户目标、规划跨步骤任务、判断
页面证据与是否停止；WebTouch 提供隔离的浏览器上下文、页面观察、受护栏约束的动作执行和
页面回执。执行结果可供 Agent 判断、向用户解释，并在有证据时沉淀为下次可复用的方法。

首个入口是仓库内 `webtouch-skill` 加 `webtouch` CLI，不新造一个目标模式或另起 MCP 服务。
`webtouch run --observe --session <ID>` 提供已有命名会话的只读观察，不需为了读取页面而发 `extract` 动作。
简单稳定任务继续用目标模式/DSL 快速完成；多步、歧义、失败恢复、敏感或需要明确证明的任务，
切到 Agent 主控的单步回路。是否增加原生 MCP 接口由真实使用中的工具往返成本决定。
CLI 版本核验按所选入口窄读帮助；同一任务内版本未变化时复用已核实能力，避免每一步重复倾倒全量帮助。

## 角色与交互

| 角色 | 负责事项 |
| --- | --- |
| Agent（Codex） | 解释目标与限制；选择执行模式；检查候选与目标是否相关；基于页面前后证据规划、停止并汇报；仅把已核实的可复用做法写入 Agent Skill/学习资产。 |
| WebTouch | 绑定并隔离任务 Target；生成页面 AX/可交互节点与截图；执行 DSL 或目标模式动作；落实页面与账号护栏；返回 URL、AXTree、截图和状态。 |
| VLM（目标模式的决策器） | 快速处理长尾视觉判断；输出建议，不取得独立于引擎护栏的执行权限。 |

## 两种工作模式

1. **快速模式**：目标简单、路径稳定、动作可逆时，用 `webtouch "目标"` 或一批 DSL。Python
   目标模式里的 VLM 每轮接收 URL、压缩 AX 内容树/可交互 refs 与截图；DSL 路径由确定性规则执行。
2. **Agent 主控模式**：多步、歧义、曾失败、涉及账号/数据变更或要求逐步证据时，Agent 对同一
   专属 `--session` 每次发送一条 DSL。Agent 读取该步回执和截图，确认候选相关性后才发下一步；
   点击后的页面结果必须符合预期。执行失败、Target 未确认接管、风险提示或证据不足都进入停止态。

不要求所有简单任务增加一次 Agent 往返。高风险任务允许速度下降，以页面证据和可解释停止为准。

## 状态与恢复

`准备 → 只读观察或执行一步 → 读取页面回执 → Agent 判断下一步`，最终进入 `完成`、`用户等待`、
`已暂停` 或 `失败待诊断`。只有达到页面侧后置条件才能标记完成。`SUCCEEDED` 是动作调用状态，
不是页面目标达成证据。Agent 在每步比较回执中的 Target ID 与 URL；任一意外变化都暂停。
有持久 session→Target 绑定时，若旧 Target 不可接管，引擎必须失败关闭，不得静默切到其他
标签；不能改用新开的空白 Target 继续同一任务。重试前先读取失败报告；不得用重复点击掩盖同一失败。
只读观察要求显式 session；CLI 只使用已就绪的 CDP 端点，不启动或重启浏览器；引擎只接受活跃上下文或
attach/profile 匹配的有效持久绑定。缺失、过期或不可接管都返回失败，不创建空白 Target，也不请求 VLM 诊断。
AX 已含目标事实时直接消费 AX，不为同一内容再发猜测式 `extract`。若回执或引擎日志显示 `no_match`，
核对候选是否存在，最多进行一次证据驱动的改写；任务级成功状态不能覆盖逐步错误。`anti-thrashing guard OPEN`
只锁触发它的那个真实账号页：不得在该页继续重试，也不得用重启掩盖真实账号风险信号；但允许换公开测试页继续验证、
允许因代码改动重启引擎、允许只读观察（2026-09-23 用户定案改写，旧版"停止所有浏览器调用、等用户确认"作废）。

## 权限边界

- 专属 session / target；不接管或挪动其他任务、用户窗口。
- WebTouch 本身是**测试环境与自有资产**：构建、重启、改代码、起停自建浏览器会话/profile 均为 Agent 已授权操作，
  不必逐次征求确认；停下线只有 `labs/AGENTS.md`「安全与停止线纪律」列出的真风险四类。
- 不绕过 WebTouch 护栏。购买、付款、提交、发帖、发消息、触发短信、改密等外部可见或安全敏感
  动作，沿用现有用户授权与在场确认边界。
- 凭证只用应用层 `@vault:<name>`；不向 Agent 暴露明文、不进 CLI 参数或日志。
- 节点存在不等于节点正确。`click`/`input` 必须有节点文本、角色、链接目标或同一行/区块证据
  对应用户目标；候选缺失、只有泛化标签或上下文不足时暂停说明缺口。
- 不把未核实的点击、VLM 猜测或单次成功回执写入 `~/.uws` learned cache。仓库内 Skill 可保存
  已验证的一般方法；页面特定缓存须等待 T-3 的页面相关性/落点证明门禁。

## AXTree 与提示词的优化方向

- **提示词硬门槛**：目标相关性必须来自节点或可见上下文；`node_id` 仅做存在性校验。无法把
  「登录密码修改」与「查看」建立证据关系时返回 impossible，不编造理由。这已加入目标模式系统提示。
- **两条 VLM 路径输入不同、证据规则一致**：Python `coordinator/goal.py` 目标模式收到 URL、压缩后的 AX 内容树/refs 和截图；
  Go 引擎 `pkg/engine/vlm_fallback.go::vlmTry` 复用既有 AX shadow 导出，只把目标命中行及最近标题作为最多 1800 字符的摘录，
  不附交互 ref 或属性块，也不增加 CDP 读取轮次。Python 与 Go 各视觉分支的 prompt 都无条件把截图/AX 中的网页内容视为不可信数据（即使 AX 为空也适用），AX 能证明
  页面语义树报告了文字但不能证明屏幕可见；位置、遮挡、布局和“屏幕上可见”的提取须由当前截图确认。
  Go 的裁剪图沿用本页摘录，`back` 后重新导出，避免前页上下文串到新页。定向 Go build/vet 与 Python py_compile 通过，
  尚未部署或 dogfood；后续仍需比较目标识别、延迟与 token 消耗，并验证 AX 命中不被误当成页面可见或动作成功。
- **AX 候选上下文（首版已实现）**：重复短标签与常见泛化动作（查看/修改/设置等）附最近
  `tr/li/[role=row]/[role=listitem]/[role=group]/.row/.item` 的可见文字摘要，最多 64 字；保留
  首个节点文本与 `node_id` 不变，避免破坏引用契约。该上下文
  通过现有 DOM BFS 同步提取，与链接 href 共用一趟遍历；并非完整父子树，也不证明动作已命中。
- **视觉自查（首版已接 CLI）**：`webtouch run --screenshot` 在成功回执附当前 Target 的本地截图路径；
  默认不开启，保持简单 DSL 路径轻量。截图路径不等于模型已看图；Agent 遇歧义时须实际调用图像查看工具打开截图，
  再结合 AX 判断，无需使用不绑定 session 的 `probe` 绕过绑定。Codex Skill 提供通用回执转图 recipe，覆盖
  `run` 成功、失败和 probe 的三种路径标签，在同一个 `functions.exec` 回合内调用一条 CLI 命令、返回完整 stdout
  与 image block；它不自动发第二条浏览器命令。无法打开截图时不得宣称已做视觉核验。
- **用户侧更快**：已知路径沿用确定性 DSL；只把需要语义判断的任务交给 Agent/VLM。在线 learned
  cache 只有在点击落点证明通过后才能启用，避免把错误变成更快、更稳定的错误。
- **本轮亲自 dogfood 的修正**：公开页面 AX 已有可见标题和链接，但 `extract:页面标题` 在两个 URL 上均记录
  `no_match`；不要把 AX 可直接读取的事实再送进语义定位。按 AX 明示 href 导航是证据充分的动作。
  新 session 的抽取又触发连续 `no_match` 熔断，因此停止运行验收，未清熔断或再次尝试。
- **VLM AX 辅助证据首版**：影子导出命中目标时，Go VLM 收到有界内容树摘录，属性块与交互 ref 树被剔除；
  所有视觉分支无条件把截图和 AX 中的网页内容视为不可信数据，即使没有 AX 也适用；抽取的文字和控件位置都要在当前截图中确认，截图是位置/可见性的唯一依据。定向 build/vet 通过，未运行测试、未部署，也未在实时页面验收。

## 验收

- Agent 能依本 Skill 在快速模式与 Agent 主控模式间作选择，沿同一 session 执行单步并读取回执。
- Agent 能以 `run --observe --session` 读取已有会话的 URL/AXTree/可选截图；不存在的绑定 fail-closed，不启动浏览器、不触发 `ExecuteAction` 或 VLM 诊断。
- 目标不在交互候选中、或只有无上下文泛化候选时，停止而不误点。
- Target 未确认切换时停止，并保留/报告原会话，而非把新空白标签当成继续成功。
- 页面后置条件有独立页面证据；未通过落点自证门禁前，不将动作写入引擎 learned cache。
